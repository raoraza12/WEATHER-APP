# Workspace Rules & Curated UI Frameworks

Whenever starting or planning any new project, Antigravity MUST proactively remember, suggest, and implement the user's saved UI frameworks according to the project's requirements:

1. **Motion Primitives** (`motion-primitives.com`):
   - **Best for:** SaaS, Dashboards, Fintech, Weather apps, Modern Consumer Web Apps.
   - **Style:** Minimalist, sleek, tactile micro-interactions, smooth spring physics, kinetic typography, translucent glass cards.

2. **Cult UI** (`cult-ui.com`):
   - **Best for:** Web3, AI Agents, DevTools, Cyberpunk, Gaming, High-Tech Dark Mode.
   - **Style:** 3D Holographic matrices, WebGL shaders, perspective tilt cards, radar telemetry, terminal HUD.

3. **Skiper UI** (`skiper-ui.com`):
   - **Best for:** Luxury Brands, Architecture, High-End Portfolios, Executive Showcases.
   - **Style:** Champagne gold accents, titanium obsidian glass, 3D rotating metallic/glass orbs, editorial serif typography.

4. **Watermelon UI** (`watermelon-tools`):
   - **Best for:** EdTech, Playful apps, Kids tools, Creative Studios, Casual Games.
   - **Style:** Vibrant neon pop colors, bouncy jelly squish physics, 3D isometric cards.
