# Curated UI/UX Libraries & Framework Guidelines

Whenever starting, planning, or designing any new project or UI feature, Antigravity MUST proactively evaluate, suggest, and utilize the following saved curated libraries based on the project's domain, aesthetic, and functional requirements:

## 1. Motion Primitives (`motion-primitives.com`)
- **Core Aesthetic:** Minimalist, sleek, tactile micro-interactions, smooth spring physics, kinetic typography, translucent glass cards.
- **Tech Stack:** Framer Motion, Tailwind CSS, Vanilla CSS & JS.
- **When to Suggest / Use:**
  - SaaS Dashboards, Web Applications, Fintech, Weather Apps, Productive Tooling, Portfolios.
  - Recommended for any project requiring high usability, production-readiness, and Apple/Linear-level fluid polish.

## 2. Cult UI (`cult-ui.com`)
- **Core Aesthetic:** Cyberpunk, 3D holographic matrices, WebGL shaders, perspective tilt cards, radar telemetry, retro grid, terminal HUD.
- **Tech Stack:** Three.js, React Three Fiber, Shader / WebGL, Tailwind.
- **When to Suggest / Use:**
  - Web3, Crypto & DeFi dashboards, AI Agents, DevTools, Cyber Security, Gaming, Hacker / Dark Mode interfaces.
  - Recommended when the user wants a futuristic "WOW factor", sci-fi feel, or high-tech telemetry.

## 3. Skiper UI (`skiper-ui.com`)
- **Core Aesthetic:** Luxury editorial, champagne gold & titanium obsidian, 3D rotating metallic/glass orbs, editorial serif typography, magazine layouts.
- **Tech Stack:** Three.js, Tailwind CSS, Editorial Typography scales.
- **When to Suggest / Use:**
  - Luxury Brands, Fashion & Haute Couture e-commerce, Architecture Studios, High-End Portfolios, Executive Summaries.
  - Recommended when the project demands elegance, premium exclusivity, and sophisticated typography.

## 4. Watermelon UI (`watermelon-tools`)
- **Core Aesthetic:** Vibrant neon pop colors (pink, mint, cyan), 3D isometric cards, bouncy jelly squish physics, neomorphic glossy bubbles.
- **Tech Stack:** CSS 3D transforms, Bouncy spring physics, SVG waves.
- **When to Suggest / Use:**
  - EdTech (Duolingo style), Creative Studios, Kids & Educational apps, Casual Gaming, Social Media tools.
  - Recommended when the project demands high energy, playfulness, cheerful visuals, and friendly interactivity.

## Mandatory Behavioral Rule for Project Planning
- At the start of any new frontend or web development task, Antigravity must classify the project type and explicitly recommend matching library styles from this curated repository to the user.
